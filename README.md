# Data Science

A collection of data analysis, forecasting, and visualization notebooks demonstrating practical application of Python's data science stack (Pandas, NumPy, Scikit-Learn, Matplotlib).

## Structure

- `notebooks/` — Jupyter notebooks, one per analysis or technique demonstrated.
- `datasets/` — Sample or public datasets used in the notebooks. Never client or proprietary data.
- `requirements.txt` — Python dependencies.

## Philosophy

Each notebook aims to show not just the technique, but the reasoning behind it — what question is being answered, why this method, and what the result means in practice.
